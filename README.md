# ChatAssistance

ChatAssistance is a SwiftUI chat client that sends questions to a local streaming chat endpoint and renders assistant responses as they arrive.

## Requirements

- Xcode
- iOS target configured in the Xcode project
- Local backend available at `http://127.0.0.1:8000/chat/stream`

## Resources

- `Resources/ChatVideo.mov` is included in the app target resources.
- Video URL: `Resources/ChatVideo.mov`

## Run

1. Open `ChatAssistance.xcodeproj` in Xcode.
2. Start the local backend server.
3. Build and run the `ChatAssistance` target.
